Customer Engagement & Product Utilization Analytics for Retention Strategy

Project Overview

This project analyzes customer engagement, product utilization, account balances, and customer churn using Excel. The objective is to identify customer segments associated with higher churn and support data-driven customer retention strategies.

Objectives

- Analyze churn rates by number of products used.
- Compare retention between single-product and multi-product customers.
- Examine average account balance by activity status.
- Explore salary-balance patterns and their relationship with churn.
- Assess churn across customer engagement profiles.

Tools Used

- Microsoft Excel 2019
- PivotTables and formulas
- Charts and dashboard visualization

Key Findings

- Overall customer churn rate: 20.37%.
- Single-product customers had a churn rate of 27.71%, compared with 12.77% for multi-product customers.
- Customers using three or four products showed high churn rates, but these groups were small and require cautious interpretation.
- The dashboard summarizes customer counts, activity, and churn patterns.

Deliverables

The Excel workbook contains the source dataset, analysis sheets, PivotTables, charts, and dashboard.

Conclusion

This project demonstrates how Excel-based customer analytics can help identify churn patterns and inform retention planning.
